# 父の持ち株ページ

父が毎日ブラウザで見られる、持ち株34銘柄のページ。
平日16:10（JST）に GitHub Actions が自動で株価を取りに行き、ページを更新する。

---

## いちばん大事なこと ― 何が公開され、何が公開されないか

**GitHub Pages のURLは、知っていれば誰でも開ける。** だから中身を2層に分けてある。

| | 内容 | 置かれ方 |
|---|---|---|
| **公開層** | 銘柄名・株価・前日比・全体の騰落率 | そのまま置く。**金額は一切入らない** |
| **秘密層** | 評価額・取得価額・含み損益・配当額 | **暗号化して置く**。あいことばがないと読めない |

暗号は **AES-256-GCM**、鍵は **PBKDF2-SHA256（25万回）** で作る。
**復号は父のブラウザの中だけで起きる。** サーバーには暗号文しか存在しない。

そして `holdings.json`（保有株数の元データ）は **`.gitignore` で除外**され、
リポジトリには入らない。GitHub には **Secret として** 渡す。

> **リポジトリを公開にしても、金額は漏れない。**
> ただし `holdings.json` だけは絶対にコミットしないこと。`.gitignore` が守っている。

## 使い始めるまで（1回だけ）

### 1. GitHubにリポジトリを作る

名前は何でもいい（例：`kabu`）。**Public で構わない**（上のとおり金額は暗号化されるため）。
GitHub Pro を持っているなら Private でもよい。

### 2. `セットアップ準備.command` をダブルクリック

`HOLDINGS_JSON` をクリップボードにコピーし、登録手順を順に表示する。
画面の指示どおり、GitHubで **2つのSecret** を登録する。

| Secret名 | 中身 |
|---|---|
| `HOLDINGS_JSON` | 保有データ（コマンドが自動でコピーする） |
| `VIEW_PASSWORD` | **父に教えるあいことば**。4文字以上、推測されにくいもの |

### 3. このフォルダを push する

```bash
cd ~/Desktop/箕面相続/株ウォッチweb
git init
git add .
git commit -m "父の持ち株ページ"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
git push -u origin main
```

### 4. Pages を有効にする

`Settings → Pages` → Source: **Deploy from a branch** → Branch: **main** / **/docs** → Save

### 5. 1回、手動で回す

`Actions` タブ →「株価を更新」→ **Run workflow**

2〜3分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が出来る。
**このURLと、あいことばを父に渡す。**

## 父の使い方

1. URLを開く（ブックマークしてもらう）
2. **いきなり値動きが見える。** ポートフォリオ全体の騰落率と、34銘柄の株価
3. 金額も見たいときは「🔒 金額を見る」にあいことばを入れる
4. **一度入れれば、そのブラウザは覚える。** 次からは自動で金額まで出る

文字は大きめ、色は上げが緑・下げが赤。スマホでも読める。

## ファイル

| | |
|---|---|
| `build_web.py` | 株探から株価と配当利回りを取得し、公開層と秘密層を書き出す |
| `encrypt.mjs` | 秘密層を暗号化する（Node標準機能のみ。追加インストール不要） |
| `docs/index.html` | 父が見るページ本体 |
| `docs/public.json` | 公開層（自動更新） |
| `docs/secret.enc` | 秘密層の暗号文（自動更新） |
| `.github/workflows/update.yml` | 平日16:10に自動実行 |
| `holdings.json` | **コミットされない。** 手元とGitHub Secretにだけ存在する |

## 手元で確認したいとき

`ローカルで試す.command` をダブルクリック。
あいことばを聞かれるので入れると、ビルドしてブラウザで開く。
**GitHubに上げる前の見た目確認用。** 終わるときは Control + C。

## 想定される詰まりどころ

**Actionsが失敗する（株価が取れない）**
株探がGitHubのIP（クラウド）を弾いている可能性がある。
その場合は自動更新をあきらめて、`ローカルで試す.command` で作ったものを
手元から push する形に切り替える。ページの作りは変えなくてよい。

**あいことばを変えたい**
`VIEW_PASSWORD` の Secret を書き換えて、ワークフローを1回手動で回す。
父のブラウザは古いあいことばを覚えているので、
**「金額を隠す」を押してから新しいものを入れ直してもらう。**

**銘柄が増減した / 株式分割があった**
`../株ウォッチ/holdings.json` を直してから、
このフォルダにコピーし直して `セットアップ準備.command` で Secret を更新する。
